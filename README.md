# DeepSeek API 客户端

一个非官方的 DeepSeek 安卓客户端。用自己申请的 DeepSeek API Key，就能在手机、平板或折叠屏上聊天。聊天记录保存在本机。

**Powered by Steven**

## 有什么功能

- 深度思考、联网搜索和流式回复，支持上传图片和文档。
- 语音输入、回复朗读，以及 Markdown、代码和公式显示。
- 支持聊天记录导入导出，可切换深浅色、调整字号。

## 怎么用

1. 到 [GitHub Releases](https://github.com/hellosteven1229-ops/deepseek-apk/releases/latest) 下载 `deepseek-api-client-debug.apk` 并安装。需要 Android 8.0 或更新版本。
2. 打开 App，进入 **设置 → 数据管理 → API Key**。点「前往 DeepSeek 开放平台获取 API Key」，创建自己的 Key。
3. 回到 App，粘贴 Key 并保存，就可以开始聊天。API 用量由 DeepSeek 开放平台计费。

## 怎么更新

打开 **设置 → 通用设置 → GitHub 发布仓库**，填入 `hellosteven1229-ops/deepseek-apk`，再点 **检查更新**。有新版时，下载安装即可，覆盖更新会保留聊天记录和设置。
